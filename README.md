# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, customer segments, product performance, discounts, subscriptions, shipping methods, and revenue trends.

The project demonstrates a complete data analytics workflow using **Python, MySQL, SQL, and Power BI**.

The main objective was to explore customer shopping data, perform SQL-based business analysis, and present the results through an interactive Power BI dashboard.

---

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- MySQL
- SQL
- Power BI

---

## 📊 Dataset

The dataset contains customer shopping information such as:

- Customer details
- Age and gender
- Items purchased
- Categories
- Purchase amounts
- Review ratings
- Discounts
- Shipping methods
- Subscription status
- Previous purchases

The dataset was obtained from the GitHub repository associated with the tutorial that inspired this project and was used for educational and portfolio purposes.

🗄️ 2. MySQL & SQL Analysis
The dataset was imported into a MySQL database named:
customer_behavior
The main table used for analysis was:
customer
SQL queries were created to answer business-related questions.
Business Questions
1. Revenue by Gender
What is the total revenue generated by each gender?
2. Discounted Purchases
Which customers used a discount but still spent more than the average purchase amount?
3. Product Ratings
Which are the top 5 products with the highest average review ratings?
4. Shipping Analysis
What is the average purchase amount for Standard and Express shipping?
5. Subscription Analysis
Do subscribed customers spend more than non-subscribed customers?
6. Discount Rate by Product
Which 5 products have the highest percentage of purchases with a discount?
7. Customer Segmentation
How can customers be segmented into New, Returning, and Loyal customers based on their previous purchases?
New: 1 previous purchase
Returning: 2–10 previous purchases
Loyal: More than 10 previous purchases
8. Product Performance
What are the top 3 most purchased products within each category?
9. Repeat Buyers & Subscription
Are customers with more than 5 previous purchases also likely to subscribe?
10. Revenue by Age Group
What is the revenue contribution of each age group?

📈 3. Power BI Dashboard
The customer data was connected to Power BI through MySQL.
An interactive dashboard was created to visualize important customer shopping patterns.
Dashboard includes:
Total Revenue
Customer analysis
Product analysis
Customer segmentation
Subscription analysis
Discount analysis
Shipping analysis
Age-group analysis
Category and purchasing trends
The dashboard helps present the analysis in an interactive and easy-to-understand format.
